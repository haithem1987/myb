# MYB Project Deployment to Render

This guide explains how to deploy the MYB microservices project to Render using the `render.yaml` configuration file.

## Prerequisites

1. **Render Account**: Create an account at [render.com](https://render.com)
2. **Git Repository**: Push your code to GitHub (Render integrates with GitHub)
3. **Environment Variables**: Prepare all required environment variables

## Architecture Overview

The MYB project deploys as:
- **5 PostgreSQL Databases**: Keycloak, Timesheet, Document, Invoice, Coproperty
- **1 Keycloak Service**: Authentication server
- **7 Backend Microservices**: User Manager, Timesheet, Document, Invoice, Payment, Notification, Coproperty
- **1 Frontend**: Angular application

## Deployment Steps

### Step 1: Connect Your GitHub Repository

1. Go to [render.com/dashboard](https://render.com/dashboard)
2. Click "New" → "Blueprint"
3. Connect your GitHub account if not already connected
4. Select the repository containing the MYB project
5. Render will automatically detect `render.yaml`

### Step 2: Configure Environment Variables

Before deploying, you'll need to set the following environment variables in your Render dashboard:

#### Required Environment Variables

```bash
# Keycloak Configuration
KEYCLOAK_ADMIN_USER=admin
KEYCLOAK_ADMIN_PASSWORD=your-secure-password
KEYCLOAK_HOSTNAME_URL=https://myb-keycloak-xxxx.onrender.com
KEYCLOAK_CLIENT_ID=MYB-client
KEYCLOAK_CLIENT_SECRET=your-keycloak-client-secret
KEYCLOAK_URL=https://myb-keycloak-xxxx.onrender.com

# Database Passwords
TIMESHEET_DB_PASSWORD=your-secure-password
DOCUMENT_DB_PASSWORD=your-secure-password
INVOICE_DB_PASSWORD=your-secure-password
COPROPERTY_DB_PASSWORD=your-secure-password

# Stripe Configuration (Payment Service)
STRIPE_SECRET_KEY=sk_test_xxxxx  # or sk_live_xxxxx for production
STRIPE_PUBLISHABLE_KEY=pk_test_xxxxx  # or pk_live_xxxxx for production

# SendGrid Configuration (Notification Service)
SENDGRID_API_KEY=SG.xxxxx
EMAIL_FROM_ADDRESS=noreply@myb.com

# Frontend Configuration
API_BASE_URL=https://myb-xxxx.onrender.com
```

### Step 3: Manual Environment Variable Configuration

1. After creating the blueprint:
   - Navigate to each service in your Render dashboard
   - Go to "Environment" tab
   - Add the environment variables listed above
   - Ensure database services use their auto-generated connection strings

2. For Keycloak hostname:
   - Deploy Keycloak first
   - Get its URL from the dashboard
   - Update `KEYCLOAK_HOSTNAME_URL` and `KEYCLOAK_URL` in other services

### Step 4: Database Initialization

After deployment, you need to:

1. **Initialize Keycloak Realm**:
   - Access Keycloak admin console
   - Create or import the MYB realm
   - Create the OAuth2 client with appropriate redirect URIs
   - Configure client credentials

2. **Run Database Migrations**:
   - For each .NET service, run EF Core migrations:
   ```bash
   # From within the service container or manually
   dotnet ef database update --project src/services/ServiceName
   ```

### Step 5: Configure Frontend URLs

Update the frontend configuration for Keycloak:

1. In `src/front/myb.front/src/environments/environment.prod.ts`:
```typescript
export const environment = {
  production: true,
  keycloak: {
    config: {
      url: 'https://myb-keycloak-xxxx.onrender.com',
      realm: 'MYB',
      clientId: 'MYB-client'
    },
    initOptions: {
      onLoad: 'login-required'
    }
  },
  apiBaseUrl: 'https://myb-frontend-xxxx.onrender.com'
};
```

## Important Notes

### Database Connections

- Each service uses its dedicated PostgreSQL database
- Connection strings are automatically generated by Render
- Use `fromDatabase` property in render.yaml to inject connection strings

### Service Dependencies

- Keycloak must be healthy before other services start
- Backend services depend on Keycloak and their respective databases
- Frontend depends on all backend services

### Scaling and Performance

- Use `plan: standard` for production workloads
- For development/testing, you can use `plan: starter` to reduce costs
- Databases use `plan: free` (suitable for development)
- For production, upgrade databases to `plan: standard` or higher

### Building and Deployment

- Render uses Docker to build and deploy services
- Each service specifies its own Dockerfile path
- Total deployment time: ~20-30 minutes for first deployment

## Troubleshooting

### Services Won't Start

1. Check environment variables are correctly set
2. Verify database services are healthy first
3. Check service logs in Render dashboard

### Database Connection Errors

1. Ensure database is running before services start
2. Verify connection string format
3. Check firewall/IP allowlist settings

### Keycloak Not Accessible

1. Wait for Keycloak to fully initialize (can take 2-3 minutes)
2. Clear browser cache
3. Verify CORS settings in Keycloak admin console
